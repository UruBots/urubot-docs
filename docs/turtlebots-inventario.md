## Protocolo de reporte de fallas o mantenimiento

Cuando un TurtleBot presente una falla mecánica, electrónica o de calibración:

1. Apagar el robot y retirar la batería con cuidado.
2. Dejar una etiqueta física sobre el robot indicando la falla.
3. Actualizar esta tabla en la documentación cambiando el estado a *En mantenimiento*.
4. Completar el formulario **Pedir ayuda** (tipo: *Mantenimiento o reporte de error*) para coordinar la reparación con el equipo de hardware.

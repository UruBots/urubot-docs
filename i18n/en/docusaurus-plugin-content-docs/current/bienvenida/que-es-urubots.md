# What is UruBots?

**UruBots** is an interdisciplinary team of applied robotics and technology development made up of students.

The main goal is learning by doing: we design, program and test robots to solve real challenges and take part in robotics competitions.

---

## Main areas of work

The team is organized around different lines of learning and projects:

- **Autonomous cars:** Scale vehicles that navigate autonomously using computer vision, sensors and control algorithms.
- **RoboCup @Home:** Service robots for home environments, focused on perception, navigation, object manipulation and human-robot interaction.
- **Educational mobile robotics (TurtleBots):** Educational platforms to learn ROS 2 concepts, kinematics and mapping.
- **Software and simulation tools:** Use of Linux, Git, Python, ROS 2 and simulation environments to validate code before testing it on hardware.

---

## How we work

- **No one is born knowing:** We don't require advanced prior knowledge. We look for enthusiasm, a desire to learn and commitment to the tasks taken on.
- **Open collaboration:** All the code and documentation we produce is shared internally so that new members can continue the path without starting from scratch.
- **Care for equipment:** Robots and sensors are shared resources that require responsibility and respect for safety protocols.
